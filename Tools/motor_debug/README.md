# 全板调试上位机

## 电机占空比范围

新版程序为 `dist/BoardDebugJointLimits.exe`。M1～M6 是小电机，正反转占空比幅值限制为 **50%～100%**；M7、M8 是大履带电机，限制为 **50%～80%**。默认仍为 80%。

电机页会按编号切换滑块上下限；板级测试、终端、关节标定、标定文件校验和 MCU 电机接口使用同一规则。低于 50% 或高于对应上限的运行命令会被拒绝。正反方向的限制相同，MCU 的板级电机接口也会再次校验，防止旧上位机或其他调用绕过范围。

**0% 仍用于停止/滑行和定位脉冲的关闭间隔**，不把停止指令抬高到 50%。灯板调光不受电机规则影响，仍允许 0%～100%。已有标定文件若包含低于 50% 的电机占空比会拒绝载入，需修正参数。

需重新烧录当前固件，使 MCU 侧限制也生效。

## 关节标定与定位（2026-10-16）

运行 `dist/BoardDebugJointLimits.exe`，新增“关节标定与定位”页。M1↔POT1 至 M6↔POT6 一一对应；M7、M8 是履带电机，继续使用原方向/占空比控制，不参加角度定位。

**本次需要重新烧录 MCU 固件**，保持 `main.c` 的 `APP_MODE` 为 `APP_MODE_DEBUG`。新版上位机检测 `CAPS JOINT 1` 后启用相关操作，旧固件不支持此功能。本次闭环接入的是 USART3 调试模式，Android 模式的 `0x31/0x34` 尚未绑定此控制器，不声明已兼容 Android extension-v1，也未修改 Android 原有帧定义。

标定步骤：

1. 选择 M1～M6 中的一个关节。切换选择会先停止全部输出。
2. 将机构移动到可准确测量的已知位置 A，停止并稳定后，填写实际角度，点击“记录当前位置 A”。
3. 移到另一个已知位置 B，角度大于 A，停止后填写角度并记录 B。两点可选在已知的安全行程内，不需要撞机械挡块，也不要求是电位器的满量程端点。
4. 选择电机正转会使**关节角度**增加还是减小。必要时先用原电机页短点动观察方向。ADC 随角度增大而下降也支持，无需改线。
5. 设置最大占空比（默认 80%）和到位容差（默认 2°），点击“下发当前关节标定”，等待 MCU 回读且提示“标定与表单一致”。该操作会停止其他输出，不启动电机。
6. 填写两点之间的目标角度和定位超时，点击“开始定位”。首次实板联调先在 M1 上使用小幅角度变化，确认方向和停位效果。

首版把 A～B 作为允许定位范围；若要覆盖更大角度，应重新选择能确认、留有机械余量的标定位置。读数范围为 1～4094，两点至少相差 100 个计数；角度范围 −360～360°，两点角度至少差 1°，跨度须大于两倍容差。容差允许 0.1～10°，实际可达精度取决于机械间隙、惯性、采样噪声和标定误差。

“保存标定文件 / 载入标定文件”使用 JSON，可以保存六个关节的参数。文件只存到电脑；载入只填表单，不会自动下发或启动。MCU 标定目前保存在 RAM，断电或复位后需手动重新下发。重连也不会自动应用电脑文件。可以查询 MCU 当前参数，再显式选择“将 MCU 参数填入表单”。文件不绑定硬件序列号，使用前请核对样机和机构。

控制策略：MCU 主循环以约 10ms 间隔扫描六路 ADC，按两点线性换算真实角度。远处按所设最大占空比接近，近处先滑行，再采用 30ms 驱动 / 100ms 滑行的短脉冲，避免把占空比降低到电机无法启动的范围。换向先停 100ms。到位容差内持续 200ms 后停止并上报 REACHED，不伪造实际角度等于目标，不持续保持，也不自动恢复。

控制时间受 ADC 和串口服务影响，不是硬件定时的严格 10ms 周期。反馈失效/超过 50ms、反馈越界、误差明显增大、2 秒没有足够进展、定位超时或硬件错误都会停止并锁定；需要显式停止/解锁后才能再次运行。HOME、串口心跳超时、上位机停止，以及开始原电机/板级测试，都取消当前定位并关闭输出。一次只定位一个关节。

终端可在已下发标定后使用：

```text
joint M1              # 查询 MCU 标定和关节状态
angle M1 45 10000     # 到 45°，超时 10000ms
stop
```

调试文本协议的新增命令（角度整数单位为毫度，非 Android 二进制命令）：

```text
CAL 10 M1 600 -30000 3400 90000 1 800 2000
# ADC_A=600, 角度A=-30°, ADC_B=3400, 角度B=90°
# 正转增加角度，80% 最大占空比，容差2°
JMOVE 11 M1 45000 10000
JGET 12 M1
```

MCU 回报 `JCAL 时间戳 Mx ADC_A 角度A ADC_B 角度B 方向 最大占空比 容差`；
`JSTATE 时间戳 Mx 已标定 反馈有效 ADC 实际角度 目标角度 输出占空比 阶段 故障`；
`JRESULT 请求序号 Mx 结果`。反馈无效时界面不显示旧角度。阶段为 IDLE / SETTLE / MOVE / DONE / FAULT；控制异常包括 SENSOR、LIMIT、STALL、DIRECTION、TIMEOUT、HARDWARE。

固件编译、主机控制测试和上位机模拟操作已验证；模拟器是生成数据，不代表实板定位精度。当前参数和短脉冲策略仍需在样机逐个关节调试。

## 命令终端

运行 `dist/BoardDebugJointLimits.exe`，连接后切换到“终端”页。终端与电机页、板级测试页共用连接、序号、心跳和停止逻辑。本次终端功能沿用上一版板级调试固件，不需要增加 MCU 命令。

```text
help
motor M1 80 500
motor M1 -80 500
lamp UP1 50 1000
buzzer 2700 1000
power 200
led 1000
adc
key
status
test
test MOTOR_M8_BI 80 500
pass
stop
```

占空比按百分数输入，最多一位小数；正负值表示电机方向，电机时长 0 表示持续运行。灯板、蜂鸣器、电源脉冲和 `test` 使用限时板级测试，输出停止后通过 `pass` / `fail` 确认。`test` 不带参数列出 29 项，`test 项目名` 使用该项目默认参数。

`adc`、`key`、`status` 查看最新缓存数据，数据超过 500ms 或断开后会提示无效；`adc test` 重新执行一次 ADC6 测试，`key test` 等待真实 HOME 按下。`log` 启动日志测试，`info` 查询固件能力。

默认隐藏周期 POT / KEY / STATE / BOARD 报文，保留命令应答、结果和事件；输入 `watch on` 显示全部连续报文，`watch off` 恢复过滤。按 ↑↓ 浏览本次窗口最近 200 条命令，Tab 补全命令、电机号、灯板名或测试项目名，Ctrl+L 清屏，输入框 Ctrl+C 或 ESC 停止全部输出。输出区可选中文字复制。

这是上位机中的 MCU 调试命令终端，命令会转换为已有串口协议，不执行 Windows / Linux 系统命令。一次只接受一行命令，未知命令及越界参数会在发送前拒绝。新打包文件名为 `BoardDebugTerminal.exe`，上一版 `BoardDebug.exe` 保留。

## 板级测试页（2026-10-15）

新增“板级测试 · 29 项”页，覆盖原全板测试表的全部项目：日志、四个指示灯循环、HOME、蜂鸣器、Linux 电源键脉冲、六路 ADC、七路灯板，以及 M1～M8 每台电机的正反转。

需要重新烧录本次编译的 MCU 固件，并保持 `main.c` 的 `APP_MODE` 为 `APP_MODE_DEBUG`。新上位机连接后查询板级测试能力，旧固件仍可使用原电机页，但板级测试按钮禁用并提示更新固件。

操作：选中项目 → 设置参数 → 点击“执行所选测试”。灯板和电机使用占空比百分数，蜂鸣器使用 Hz；其余项目无幅值参数。LED 时长是每盏灯的保持时间，KEY 时长是等待真实按键输入的超时，其他时长是一次输出的持续时间。电机测试最长 5000ms，电源脉冲和蜂鸣器最长 10000ms。

所有测试串行执行；开始新测试或直接运行电机，会取消当前测试并关闭原输出。灯板、蜂鸣器、电源键和电机到时自动关闭，四个 LED 轮流点亮后关闭，随后点击“确认通过”或“标记失败”。这类 PASS 是操作员观察结果，不代表 MCU 自动测得光、声音或转动。

LOG 根据调试发送是否成功自动判定；ADC6 根据实际六路扫描是否成功自动判定，不代表六路精度和接线已验证。KEY 检测板上 HOME 自动通过或超时失败，HOME 同时触发通用停止锁定，松开后点击全部输出停止解锁。板级页显示按键原始状态与累计次数，电位器读数和曲线保留在原电机页。

结果表按命令序号对应测试请求，记录通过、人工失败、硬件/通信失败、超时和取消；失联时未取得结果的项目标记为结果未知。连接状态、测试状态或采样过期时禁用相应操作或标记数据无效。

本次更新后“全部停止”、HOME、心跳超时和串口异常会关闭电机、灯板、蜂鸣器、指示灯并释放 Linux 电源键。PWR 是单次电源键脉冲，实际作用于连接的 Linux；如需观察重复脉冲，可重复执行该项目。

扩展文本命令：

```text
INFO 10                         # ACK 10 INFO，然后 CAPS BOARD_TEST 2
TEST 11 LED 0 1000              # 四灯依次各保持 1000ms
TEST 12 BUZZER 2700 1000        # 2700Hz，1000ms
TEST 13 PWR 0 200               # 单次 200ms 电源键脉冲
TEST 14 LAMP_UP1 500 1000        # UP1，50%，1000ms
TEST 15 MOTOR_M1_BI 800 500      # M1 反转，80%，500ms
CONFIRM 16 PASS                 # 输出结束后的人工确认；失败使用 FAIL
```

MCU 通过 `RESULT <请求序号> <项目名> <结果>` 上报结果，`BOARD <时间戳> <项目名> <阶段>` 上报测试状态，`KEY <时间戳> <原始按下状态> <累计次数>` 上报 HOME。阶段包括 SETTLE、DRIVE、WAIT、KEY、IDLE。电机测试期间 STATE 也回报该路实际指令占空比。

模拟模式可操作全部 29 项；模拟 KEY 在一秒后生成按下事件，不控制真实硬件。

通过 USART3 调试串口控制 M1～M8，同时查看 POT1～POT6。MCU 烧录一次调试固件后，后续切换电机、调整方向、占空比和点动时长都在窗口完成。

## 使用

1. 在 `MCU/software/test_bringup` 构建 Debug 固件，按工程现有 F5 流程烧录。当前 `main.c` 已接入串口调试模式，上电全部电机停止。
2. USB 转串口使用 3.3V TTL：适配器 TX 接 PB11/USART3_RX，RX 接 PB10/USART3_TX，GND 共地。电机由板上的电机电源供电。
3. 关闭占用同一 COM 口的串口助手。运行 `dist/BoardDebugJointLimits.exe`，或双击 `start.bat`（需要 Python 3.10 及以上和 Tkinter；首次安装 pyserial）。
4. 选择 COM 口，点击连接。程序会发送 PING 和 STOP，收到 MCU 应答后显示已连接；不会自动启动电机。
5. 默认 M1、80% 占空比、500ms 点动。点击正转/反转点动测试，或使用持续运行。滑块改变参数，点击运行才生效；切换电机选择会先发送全部停止。
6. 点击全部停止，按 ESC，或按板上的 HOME 停止。HOME/断线/串口错误后会锁定停止，松开 HOME 后点击“全部停止 / 解锁”，再重新发运行命令。

数值区显示六路原始 ADC 值（0～4095）和相对基准的变化量；首次采样自动设置基准，按钮可以重新设置。曲线保留最近 30 秒，可勾选需要显示的通道。电机与电位器的对应关系尚未标定，界面不会把某个 POT 预设为某台电机的角度。

上位机每 200ms 发送 PING；MCU 最后一次有效 PING 超过 1000ms 后停止并锁定。主动断开或关闭窗口会尽力发送 STOP；电缆拔出、进程退出时依靠 MCU 心跳超时停止。重新连接和恢复心跳不会自动恢复运行。

## 串口协议 v1

115200 / 8N1，无流控。ASCII 文本，每条以 LF 结束，兼容 CRLF。序号 0～65535。

| 请求 | 含义 |
|---|---|
| `PING 1` | 更新心跳；返回 `ACK 1 PING` |
| `RUN 2 M1 800 500` | M1 正转，800‰，运行 500ms |
| `RUN 3 M8 -800 0` | M8 反转，800‰，持续运行，仍需心跳 |
| `STOP 4 ALL` | 全部滑行停止；HOME 松开后清除停止锁定 |

RUN：电机 M1～M8，非零占空比 −1000～1000‰，时长 0～60000ms。运行前必须有最近 1 秒内的 PING，且不能处于锁定状态。新 RUN 先停全部电机，再等待 100ms 启动；点动时长从实际开始驱动时计算。

| 回复 / 上报 | 含义 |
|---|---|
| `ACK 2 QUEUED` | 接受运行请求，等待启动；实际指令状态由 STATE 上报 |
| `ACK 4 STOP` | 停止并解锁 |
| `ACK 4 STOP_LOCKED` | 已停止，HOME 仍有效，保持锁定 |
| `ERR 2 LOCKED` | 停止锁定，拒绝运行 |
| `ERR 2 NO_HEARTBEAT` | 无新鲜心跳，拒绝运行 |
| `ERR 2 PARAM` | 命令/参数错误 |
| `POT 12345 1000 1500 2000 2500 3000 3500` | MCU 毫秒时间戳 + 六路原始 ADC，每 100ms 上报 |
| `STATE 12345 1 800 0 0` | 时间戳、电机号（0=停止）、有符号指令占空比、是否等待启动、是否锁定 |
| `ADCERR 12345 -6` | 采样失败，本次不返回 POT；界面标记数据无效 |
| `EVENT DONE` | 点动完成 |
| `EVENT HOME` / `TIMEOUT` / `UART_ERROR` / `BAD_LINE` / `HARDWARE` | 停机原因 |

STATE 表示电机控制指令，不表示测得的转速或确认电机已停稳。六路 ADC 使用现有扫描 DMA 接口，单次等待上限 5ms；串口每次发送等待上限 15ms。HOME 在主循环检查，也检查中断累计次数。UART 接收使用中断和 256 字节环形缓冲；超长行、非法字符、接收溢出和串口错误会停止并锁定。停止属于滑行，不使用短路制动。
