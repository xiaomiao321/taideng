# 电源板首板测试流程 v0.1

> 适用对象：当前已焊接的电源板首板  
> 依据文件：`电源板/电源网表.tel`  
> 测试目标：先确认无短路和装配错误，再验证开关、保护、各路输出、带载能力、纹波、温升和多路负载相互影响。  
> 原则：**先限流、后升压；先空载、后带载；先单路、后联合；发现异常立即断电。**

## 0. 上24V前必须处理的事项

### 0.1 核对并更换U20、U21

当前网表中：

- U20、U21型号为`KM1E221M0611`；
- 容量为220µF；
- 两者直接连接在`VIN_24_PROT`与GND之间；
- 该型号的额定耐压为25V。

**如果实物上确实标有“220µF 25V”，不得直接进行24V上电和负载测试。** 24V已经达到额定耐压的96%，没有给适配器误差、插拔尖峰和TVS钳位过程留下足够裕量。

处理要求：

- 至少更换为220µF/35V；
- 更推荐220µF/50V、105℃、低ESR型号；
- 更换前确认直径、脚距和高度能够安装；
- 两只电容的负极必须接GND，正极接`VIN_24_PROT`。

完成更换并复查极性后，才允许进入24V测试。

### 0.2 确认输入方式

本板存在XT60、DC插座和大焊盘等多个输入位置。测试时只使用其中一个输入，其他输入口保持悬空，禁止同时接入两个电源。

- 输入正极：`VIN_24_RAW`
- 输入负极：GND
- 推荐第一次使用XT60或大焊盘输入；
- 使用万用表确认输入接口极性，不能只看插座外形判断。

### 0.3 当前各路额定测试目标

| 输出 | 当前整机需求 | 首板验证目标 | 说明 |
|---|---:|---:|---|
| `+12V` | 12V/5A | 5A连续 | 电机电源 |
| `+5V_Core` | 5V/5A | 5A连续 | Linux核心板专用 |
| `+5V_AUX` | 当前至少5V/2A | 先验证2A | 后续负载未完全冻结，不要盲目提高 |
| `+3V3` | 待主控板确认 | 分级验证至模块设计值，暂不超过2A | 由`+5V_AUX`二次降压 |
| `+24V_Lamp` | 24V/2A | 2A连续 | 受控24V直通输出 |

> `+24V_Lamp`支路当前安装的是6.3A保险丝F1。它可以保护严重短路和板上大电流通路，但不等于把灯板电流限制在2A。若最终线束和灯板只按2A设计，应再评估改为2.5～3A保险丝。

## 1. 测试设备

最低配置：

- 0～30V可调直流电源，支持电流限制；
- 两只数字万用表；
- 可调电子负载；
- 示波器和10×探头；
- 热像仪或热电偶温度计；
- 绝缘镊子、放大镜、耐热绝缘测试垫；
- 备用保险丝。

建议：

- 单路满载测试时，电源至少能输出24V/5A；
- 多路联合满载时，电源最好能输出24V/10A以上；
- 电子负载功率应覆盖12V×5A=60W和5V×5A=25W；
- 初次上电不要连接Linux板、灯板、电机或其他贵重负载。

## 2. 电路节点和开关对应关系

### 2.1 输入和总开关

```text
VIN_24_RAW
  → U2（15A总保险丝）
  → VIN_24_FUSED
  → U3 + Q1（LM74700反接/反向电流保护）
  → VIN_24_PROT
  → Q2、Q3（并联总电源MOS，由SW2控制）
  → VIN_24_SW
```

| 功能 | 器件 | 相关节点 |
|---|---|---|
| 总电源输入 | XT60 U8、DC1或输入焊盘U9/U10 | `VIN_24_RAW`、GND |
| 总保险丝 | U2，AF2-15.0V065TM | `VIN_24_RAW`→`VIN_24_FUSED` |
| 反接保护 | U3、Q1 | `VIN_24_FUSED`→`VIN_24_PROT` |
| 总开关 | SW2、Q2、Q3 | `VIN_24_PROT`→`VIN_24_SW` |

### 2.2 支路开关

| 开关 | 支路 | 保险丝 | 功率MOS | 电源模块/输出 |

| SW3 | Linux核心板 | F2，3A | Q5 | U23→`+5V_Core` |
| SW4 | 5V辅助及3.3V | F3，3A | Q6 | U4→`+5V_AUX`，再经U6→`+3V3` |

| 网络 | 测量位置 |
|---|---|
| `VIN_24_RAW` | H7正端对H7地端，或输入焊盘 |
| `VIN_24_FUSED` | H6正端对H6地端 |

## 3. 第一次上电前检查

### 3.1 外观检查

断电状态下逐项确认：

- [ ] U20、U21已换成至少35V耐压，推荐50V；
- [ ] 所有电解电容正负极与PCB标识一致；
- [ ] LED极性正确；
- [ ] D7、D8、D9、D10、U5等单向TVS的阴极接对应正电源，阳极接GND；
- [ ] D2为双向`SMBJ28CA`，安装方向不影响功能；
- [ ] Q1、U3、Q2～Q7方向与1脚标记一致；
- [ ] DC-DC模块输入、输出和GND没有接反；
- [ ] Q1和U3细间距焊点无连锡、虚焊；
- [ ] 保险丝、连接器、开关插件焊点已充分上锡；
- [ ] 板底无锡珠、剪脚、裸线或金属异物；
- [ ] 大电流焊点不存在明显裂纹和孔内未吃锡；
- [ ] 板下垫绝缘材料，不能直接放在金属桌面上。

### 3.2 保险丝通断检查

用万用表通断档测量：

- U2、U7、F1、F2、F3两端应导通；
- 不应通过人为短路的方式验证保险丝熔断；
- 首次上电时台式电源限流值远低于15A，因此输入总保险丝不会代替限流电源保护首板。

### 3.3 各电源网络对地阻值

所有开关置于断开状态，依次测量：

| 网络 | 实测阻值/现象 | 判定 |
|---|---:|---|
| `VIN_24_RAW`→GND |  |  |
| `VIN_24_FUSED`→GND |  |  |
| `VIN_24_PROT`→GND |  |  |
| `VIN_24_SW`→GND |  |  |
| `+24V_Lamp`→GND |  |  |
| `+12V`→GND |  |  |
| `+5V_Core`→GND |  |  |
| `+5V_AUX`→GND |  |  |
| `+3V3`→GND |  |  |

判断方法：

- 电容充电时阻值可能先低后逐渐升高，这是正常现象；
- 如果某一路稳定保持在1Ω以下，应视为疑似硬短路，不得上电；
- 5V Core和5V AUX应彼此隔离，不能直接导通；
- 对可疑支路使用二极管档正反向复测，并优先检查TVS、电解电容和模块焊接方向。

### 3.4 开关触点逻辑检查

不接电源，用通断档确认每个开关的实际状态：

- SW2的2脚接GND时为总电源开启；2脚悬空/接NC时为关闭；
- SW1、SW3、SW4、SW5按下自锁后，应将对应控制节点接GND；
- 在文档和PCB上标记清楚“按下”和“弹起”哪个状态为ON，不能只凭手感判断。

## 4. 第一次限流上电

### 4.1 准备

1. 不连接任何外部负载。
2. SW2、SW1、SW3、SW4、SW5全部关闭。
3. 台式电源先设置为0V，电流限制设为50mA。
4. 关闭台式电源输出后再接线：正极接`VIN_24_RAW`，负极接GND。
5. 万用表固定监测`VIN_24_PROT`。

### 4.2 分级升压

依次执行，每一级停留约10秒：

| 输入设定 | 观察内容 | 合格现象 |
|---:|---|---|
| 5V | 输入电流、异常发热 | 不顶到50mA限流，无器件快速升温 |
| 12V | `RAW/FUSED/PROT`电压 | 三级节点随输入上升，无明显压降 |
| 20V | 输入电流和LED7 | 输入电流稳定，无焦味和异响 |
| 24V | 最终空载状态 | LED7亮，`VIN_24_PROT`接近24V |

24V、所有开关关闭时：

- 输入电流原则上应处于毫安级；
- 暂以小于20mA作为首板检查参考值；
- 若电源进入恒流模式、输入电流持续上升、器件温度快速升高或出现异味，立即关闭输出。

## 5. 总开关测试

保持24V输入，仍不连接外部负载：

1. 将电源限流提高至100mA。
2. SW2保持OFF，测量`VIN_24_SW`，应接近0V。
3. 操作SW2至ON，测量`VIN_24_SW`，应接近`VIN_24_PROT`，LED2应点亮。
4. 再关闭SW2，确认LED2熄灭；由于下游电容储能，电压可能缓慢下降。

建议测量Q2、Q3：

- OFF时：各管`VGS≈0V`；
- ON时：栅源之间应出现负压，12V稳压管会限制其绝对值；
- 测`VGS`时表笔必须直接跨接G与S，不能把栅极对地电压误当成`VGS`。

## 6. 各支路空载测试

总开关SW2打开，支路一次只打开一路。第一次测试各DC-DC支路时，将输入限流设为300mA；确认稳定后再逐步增加。

### 6.1 12V支路

1. 打开SW1，其余支路关闭。
2. 确认LED1亮。
3. 测量U1输入和`+12V`。
4. 关闭SW1，确认输出能够下降，不要用螺丝刀直接短接电容放电。

### 6.2 5V Core支路

1. 打开SW3，其余支路关闭。
2. 确认LED5亮。
3. 测量U23输入和`+5V_Core`。
4. 此时不要把U11 USB-A口插入电脑。U11是5V输出口，插入电脑可能造成两路5V电源互相回灌。

### 6.3 5V AUX和3.3V支路

1. 打开SW4，其余支路关闭。
2. 确认LED4和LED6亮。
3. 先测`+5V_AUX`，确认正常后再测`+3V3`。
4. 如果5V正常而3.3V异常，立即关闭SW4并检查U6方向和外围焊接。

### 6.4 24V灯板支路

1. 打开SW5，其余支路关闭。
2. 确认LED3亮。
3. 测量`+24V_Lamp`，应接近`VIN_24_SW`。

### 6.5 空载电压判据

首轮以±5%作为基本门槛，稳定后按更严格目标检查：

| 输出 | 基本允许范围 | 推荐目标 |
|---|---:|---:|
| `+24V_Lamp` | 随输入，约22.8～25.2V | 与`VIN_24_SW`压差小于0.2V |
| `+12V` | 11.4～12.6V | 11.8～12.2V |
| `+5V_Core` | 4.75～5.25V | 4.90～5.10V |
| `+5V_AUX` | 4.75～5.25V | 4.90～5.10V |
| `+3V3` | 3.14～3.47V | 3.20～3.40V |

## 7. 单路电子负载测试

### 7.1 通用步骤

每次只测试一路：

1. 关闭输入电源和全部开关。
2. 把电子负载接到被测输出端，确认正负极。
3. 电子负载设为CC模式，从0A开始。
4. 开启输入、总开关和对应支路。
5. 逐级增加电流，每级记录输出电压、输入电流、纹波和最高温度。
6. 达到目标电流后持续运行30分钟，每5分钟记录一次。
7. 关闭时先把电子负载降至0A，再关闭支路和输入电源。

禁止事项：

- 禁止直接短路输出测试保险丝；
- 禁止在输出带电时插拔杜邦线或裸线；
- 禁止让电子负载夹子相互接触；
- 禁止在温升失控时继续等待“看看会不会稳定”。

### 7.2 电流阶梯

| 支路 | 建议测试点 |
|---|---|
| 12V | 0.5A→1A→2A→3A→4A→5A |
| 5V Core | 0.5A→1A→2A→3A→4A→5A |
| 5V AUX | 0.5A→1A→1.5A→2A；更高电流等需求和模块规格确认后再测 |
| 3.3V | 0.1A→0.5A→1A→1.5A→2A，仅在U6确认支持2A时执行最后一级 |
| 24V Lamp | 0.5A→1A→1.5A→2A |

输出端与负载端的电压差用于判断线束和连接器压降。5V Core在负载实际入口处不应低于4.75V。

## 8. 纹波测试

示波器设置建议：

- 探头10×；
- AC耦合；
- 打开20MHz带宽限制；
- 使用短接地弹簧，不用十几厘米长的鳄鱼夹地线；
- 探头直接跨接输出电容正负端；
- 示波器地夹只能接板上GND，不能夹到高边MOS源极或开关节点。

首板参考目标：

| 输出 | 满载纹波参考目标 |
|---|---:|
| 5V Core | 优选≤50mVpp，基本要求≤100mVpp |
| 5V AUX | ≤100mVpp |
| 3.3V | 优选≤30mVpp，基本要求≤50mVpp |
| 12V | ≤200mVpp |
| 24V Lamp | 主要检查尖峰和输入适配器纹波，建议≤200mVpp |

若看到高频尖峰：

1. 先确认探头接地方式；
2. 再检查输出小电容是否靠近模块及焊接是否良好；
3. 比较模块输出脚、PCB输出端和负载端三处波形；
4. 不要在未排除测量伪影前随意增大电容。

## 9. 温升测试

每一路满载30分钟，重点观察：

- U1、U4、U6、U23电源模块；
- Q1～Q7；
- U2、U7、F1、F2、F3保险丝；
- XT60、螺丝端子、USB-A和其他输出连接器；
- U20、U21及各输出电解电容；
- 大电流走线的最窄处和过孔区域。

首板工程判据建议：

- 温升≤20℃：较好；
- 温升20～35℃：记录并关注外壳内环境；
- 温升>35℃：需要检查铜皮、焊接、接触电阻或器件余量；
- 任意器件超过80℃、持续快速升温、变色、异味或异响：立即断电；
- 最终还需在接近实际封闭外壳的条件下复测，开放桌面温度不能代表整机温度。

## 10. 负载阶跃和开关测试

电子负载支持动态模式时：

### 10.1 5V Core

- 负载在0.5A与4A之间切换；
- 先用10Hz，再用100Hz；
- 观察最低电压、最高电压和恢复时间；
- 建议负载端最低不低于4.75V、最高不高于5.25V；
- 不应出现模块反复重启或输出长时间振荡。

### 10.2 12V

- 负载在0.5A与5A之间切换；
- 观察输出跌落、过冲和模块保护动作；
- 如果电子负载无法模拟电机启动，后续再使用真实电机测试启动和堵转瞬态。

### 10.3 支路开关

- 在小负载下反复开关每路10次；
- 观察输出是否每次正常建立；
- 检查开关、MOS和连接器是否出现打火、异常发热；
- 大电流满载时不要频繁机械开关，先从0.2～0.5A验证。

## 11. 多路联合负载测试

单路全部通过后再执行。

### 11.1 半载联合测试

建议先接：

- 12V：2.5A；
- 5V Core：2.5A；
- 5V AUX：1A；
- 24V Lamp：1A；
- 3.3V根据实际需求接0.5A。

运行15分钟，确认总输入、总MOS、保险丝、连接器和铜皮温升正常。

### 11.2 需求满载联合测试

在电源、电子负载和线束能力足够的前提下：

- 12V：5A；
- 5V Core：5A；
- 5V AUX：2A；
- 24V Lamp：2A；
- 3.3V按实际负载测试，注意其功率来自5V AUX。

持续运行30分钟，记录：

- 24V输入电压和输入电流；
- 每一路输出电压；
- `VIN_24_RAW`、`VIN_24_FUSED`、`VIN_24_PROT`、`VIN_24_SW`之间的压降；
- 总开关MOS、反接保护MOS、保险丝和连接器温度；
- 开关12V负载时，5V Core是否出现明显跌落；
- 开关24V Lamp时，3.3V和5V是否受到干扰。

总输入通路参考要求：

- `VIN_24_RAW`到`VIN_24_PROT`的压降应尽量小；
- `VIN_24_PROT`到`VIN_24_SW`的压降建议小于0.2V；
- 如果压降或发热明显，分别测量保险丝、MOS、焊盘、连接器两端，定位接触电阻最大的部位。

## 12. 保护功能验证边界

### 12.1 保险丝

本轮首板功能测试只确认额定值、通断和正常负载温升，不建议人为短路烧断保险丝。若必须验证熔断特性，应使用单独样板、备用保险丝、隔离防护和可记录电流波形的设备。

### 12.2 TVS

不得通过把普通台式电源缓慢升到TVS击穿电压来验证TVS。这样可能使TVS持续耗散并损坏，也不能等效真实浪涌。

本轮只检查：

- 型号和方向正确；
- 在额定电压下没有明显漏电和发热；
- 额定工作时输出不被钳低。

浪涌能力需要专用脉冲/浪涌设备再测。

### 12.3 反接保护（可选）

正常极性测试全部通过后才做：

1. 断开所有负载并关闭全部开关；
2. 电源设为5V、限流20mA；
3. 确认输入接口定义无误后短时间反向连接；
4. `VIN_24_PROT`不应建立正常正电压，所有输出LED应保持熄灭；
5. 立即断开并检查Q1、U3是否发热。

不熟悉反接测试时可以跳过，不能直接从24V反接开始。

## 13. 接入真实负载的顺序

电子负载测试通过后，按以下顺序接入：

1. 先接普通电阻性或低价值测试负载；
2. 再接24V灯板，限流从0.5A开始；
3. 再接单个电机，先空载启动，再逐步增加机械负载；
4. 最后接Linux核心板；接入前再次确认5V Core极性和电压；
5. Linux板第一次开机时，24V输入限流不能设得过低，否则启动峰值会造成误复位；
6. 真实负载联调时持续监视5V Core，避免电机启停导致Linux重启。

## 14. 整板验收条件

以下项目全部满足，才建议进入整机联调：

- [ ] U20/U21耐压问题已处理；
- [ ] 全板无短路、反件、错件和明显虚焊；
- [ ] 总开关及四个支路开关逻辑正确；
- [ ] 所有指示灯对应关系正确；
- [ ] 12V可连续输出5A；
- [ ] 5V Core可连续输出5A，负载端不低于4.75V；
- [ ] 5V AUX至少通过2A测试；
- [ ] 3.3V通过实际设计负载测试；
- [ ] 24V Lamp通过2A测试；
- [ ] 输出纹波满足第8节参考目标；
- [ ] 满载30分钟无异常温升、异味、异响和保护误动作；
- [ ] 多路同时工作时各路电压稳定；
- [ ] 电机或灯板开关动作不会导致5V Core异常跌落；
- [ ] USB-A 5V输出口不会被误接到电脑USB口；
- [ ] 测试数据、热像图和示波器截图已保存。
