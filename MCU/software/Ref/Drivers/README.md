# STM32 电机驱动与角度闭环代码说明

这份代码用于在 **STM32F1 + HAL** 环境中驱动 RZ7899 H 桥直流电机，并通过电位器读取输出轴角度。代码还附带一个闭环联调示例，让电机依次转到若干目标角度并停稳。

## 目录结构

```text
Drivers/
├─ RZ7899/             RZ7899 H 桥电机驱动
├─ PotAngle/           电位器角度采样与换算
└─ AnglePositionTest/  组合前两者的角度闭环定位示例
```

每个子目录均包含一个 `.c`、一个 `.h` 和一份更详细的 `README.md`。

## 整体数据流

```text
PA4 / ADC1_IN4
      │
      ▼
PotAngle_Update()
  连采平均 → 可选 IIR → 标定映射 → 当前角度
      │
      ▼
AnglePositionTest_Update()（建议每 1 ms 调用）
  目标角度 - 当前角度 → 两段速度控制 → 到位制动 / 故障停机
      │
      ▼
RZ7899_Start() / RZ7899_Stop()
      │
      ▼
RZ7899_Update()（每个 PWM 周期调用，例：20 kHz）
  换向死区 → 可选启动助推 → 占空比斜坡 → TIM 两路 PWM
      │
      ▼
RZ7899 FI / BI → 直流电机
```

## 1. RZ7899：电机底层驱动

`Drivers/RZ7899` 封装了 RZ7899 双输入 H 桥的控制。调用者传入一个定时器和两个 PWM 通道，不在库内写死定时器或引脚。

主要能力：

- 用 `-1000 ~ +1000` 表示速度和方向，正负号表示正反转；
- 支持低速死区补偿和最高占空比限制；
- 支持线性软启动、软停止以及立即短路制动；
- 换向前先关闭两路输出并等待死区，减小反向冲击；
- 所有控制接口均为非阻塞，内部状态机由 `RZ7899_Update()` 推进；
- 自动根据 RCC、PSC 和 ARR 计算 PWM 频率，并把毫秒斜坡时间换算成 PWM 周期数。

关键接口：

| 接口 | 作用 |
|---|---|
| `RZ7899_Init()` | 绑定定时器和两个 PWM 通道，启动零占空比输出 |
| `RZ7899_SetDutyLimits()` | 设置电机可用的最小、最大占空比 |
| `RZ7899_SetRampTimes()` | 设置启停斜坡时间 |
| `RZ7899_Start()` | 按斜坡启动或改变目标速度 |
| `RZ7899_SetSpeed()` | 立即改变速度；换向仍保留安全死区 |
| `RZ7899_Update()` | 推进换向、助推和斜坡状态机，必须周期调用 |
| `RZ7899_Stop(...COAST)` | 斜坡减速后高阻滑行 |
| `RZ7899_Stop(...BRAKE)` | 两路 100% 输出，立即短路制动 |
| `RZ7899_DeInit()` | 输出归零并关闭 PWM 通道 |

当前示例接线为：

| STM32 | RZ7899 | 用途 |
|---|---|---|
| PA0 / TIM2_CH1 | FI | 正转 PWM |
| PA1 / TIM2_CH2 | BI | 反转 PWM |
| GND | GND | 必须共地 |

示例参数为 TIM2 `PSC=0`、`ARR=3599`，在 72 MHz 定时器时钟下得到 20 kHz PWM。代码中还记录了两组实测启动占空比：蜗杆减速电机约 55%，履带电机约 54%。这些值是特定样机的标定结果，换电机、电源或负载后应重新标定。

## 2. PotAngle：电位器角度采样

`Drivers/PotAngle` 从 ADC 读取与电机同轴的 270° 电位器，将原始 ADC 值转换为整数角度。

采样链为：

```text
N 次 ADC 连采 → 算术平均 → 可选一阶 IIR → 两端点线性映射 → 0~270°
```

默认每帧采 8 次，IIR 关闭，以低延迟为主。端点理论值为 87 和 4008，实际装机后应把机构转到两端，读取原始值并重新标定。

关键接口：

| 接口 | 作用 |
|---|---|
| `PotAngle_Init()` | 绑定 ADC、执行 F1 ADC 校准并先采一帧 |
| `PotAngle_Update()` | 完成一帧采样、滤波与角度换算 |
| `PotAngle_SetEndpoints()` | 设置 0° 和 270° 对应的 ADC 值 |
| `PotAngle_SetFilter()` | 修改连采次数和 IIR 系数 |
| `PotAngle_Get*()` | 读取原始值、平均值、滤波值或角度 |

硬件假设是 PA4 / ADC1_IN4、12 位右对齐、软件触发单次转换。由于电位器源阻抗较高，文档要求 ADC 采样时间至少 71.5 周期。

## 3. AnglePositionTest：角度闭环联调示例

`Drivers/AnglePositionTest` 不是通用 PID 控制器，而是一个便于台架验证的简单双段式位置控制器。默认依次前往：

```text
30° → 60° → 90° → 120° → 150° → 200° → 260°
```

控制逻辑：

1. 读取当前电位器角度；
2. 计算 `目标角度 - 当前角度`；
3. 离目标较远时用速度 400，进入 20° 范围后降到速度 150；
4. 误差不超过 2° 时立即制动；
5. 停稳 1 秒后进入下一个目标；
6. 连续 3 秒没有至少 2° 的改善时，认为方向错误、触及限位或发生卡死，制动并锁定 `fault`；
7. 全部目标完成后继续保持最后一个角度。

这是一种“开关/两段速度 + 迟滞”的控制，并没有比例、积分、微分项。优点是简单、容易联调；缺点是精度、平顺性和抗负载变化能力不如经过调参的闭环控制器。

## 最小集成方式

```c
#include "pot_angle.h"
#include "rz7899.h"
#include "angle_position_test.h"

PotAngle_Handle pot1;
RZ7899_Handle motor1;
AnglePositionTest_Handle position_test;

/* 外设初始化完成后 */
PotAngle_Init(&pot1, &hadc1);
RZ7899_Init(&motor1, &htim2, TIM_CHANNEL_1, TIM_CHANNEL_2);
RZ7899_SetDutyLimits(&motor1,
                     RZ7899_MOTOR_TRACK_MIN_DUTY,
                     RZ7899_MOTOR_TRACK_MAX_DUTY);
RZ7899_SetRampTimes(&motor1, 100U, 100U);
AnglePositionTest_Init(&position_test, &motor1, &pot1);

/* TIM2 更新中断中，每个 PWM 周期调用一次 */
RZ7899_Update(&motor1);

/* 主循环或 1 kHz 任务中 */
AnglePositionTest_Update(&position_test);
```

实际工程还需要把三个目录加入头文件搜索路径，并编译三个 `.c` 文件。`rz7899.h` 和 `pot_angle.h` 当前直接包含 `stm32f1xx_hal.h`，因此代码默认面向 STM32F1；移植到其他 STM32 系列时需要替换 HAL 头文件，并重新核对定时器时钟计算规则。

## 使用前必须确认

- `RZ7899_Update()` 的调用频率必须与实际 PWM 周期一致，否则换向死区和斜坡时间都会失真；
- `AnglePositionTest_Update()` 中的计数器按“一次调用等于 1 ms”解释，若调用周期不是 1 ms，停稳时间和卡死超时都会失真；
- 首次闭环上电会立即向 30° 运动，应预留急停/断电手段；
- 若角度误差越来越大，应立刻断电，然后修改 `dir_sign` 或对调电机线；
- 默认最大目标 260°，距离 270° 电位器机械端只有 10°，必须确认机构行程和安装零位；
- `BRAKE` 是短路制动，高速或长时间保持时可能产生较大电流和发热；
- 这套代码没有电流检测，所谓“卡死看门狗”只根据角度是否继续接近目标判断，不能替代硬件过流保护。

## 代码审阅结论与建议

整体上，代码分层清楚、注释完整，底层驱动采用非阻塞状态机，且处理了换向死区、斜坡重规划、启动失败回滚和输入限幅，适合作为当前硬件的联调驱动。不过在正式装车或长期运行前，建议处理以下事项：

1. **修正 IIR 对负误差的舍入。** `pot_angle_iir()` 当前统一给差值加正的半个除数；当 `target` 比 `current` 小且只差 1 个 ADC 计数时，滤波值可能不再下降。应按差值正负分别加/减半个除数，或明确采用向零截断策略。
2. **把控制周期显式传入或改为 tick 时间。** `stall_ms`、`dwell_ms` 名称是毫秒，但实现只是每次 `Update()` 加 1；当前只有在严格 1 kHz 调用时才等价于毫秒。
3. **增加可在主机运行的单元测试。** 建议至少覆盖速度限幅、占空比映射、换向死区、连续改目标、软/硬停止、ADC 端点映射、IIR 正反向收敛和闭环卡死判断。
4. **校验运行期端点参数。** `PotAngle_SetEndpoints()` 会接受反向或相同端点，随后角度恒为 0。更稳妥的接口应返回 `bool` 并拒绝非法参数。
5. **考虑制动释放策略。** 定位示例到位后持续保持短路制动；如果机构需要长时间保持，应实测驱动芯片和电机温升，必要时在短暂制动后切换为滑行、低占空比保持或机械自锁方案。
6. **区分演示参数与产品参数。** 54%/55% 启动占空比、2° 容差、20° 换挡点和 3 秒看门狗都来自当前样机假设，不宜直接视为所有电机的默认安全参数。

## 建议的上电调试顺序

1. 电机脱离负载，只测试 `RZ7899_SetSpeed()` 的正反方向和急停；
2. 关闭电机，转动机构并观察 `PotAngle` 的原始值与角度方向，完成两端点标定；
3. 低占空比、远离机械端点测试闭环方向；
4. 把目标序列临时改为中间行程的小范围，例如 90°、120°、150°；
5. 确认方向、卡死保护和制动温升后，再恢复完整目标序列并带载测试。
