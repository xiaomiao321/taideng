# MCU 主控板已知硬件问题

> 更新日期：2026-10-09
> 适用范围：当前 STM32F407 主控板（`ProPrj_AI台灯_模块版_2026-09-22.epro`）
> 用途：记录首板调试中发现的硬件问题、根因和排查方法，供第二批板与生产排查参考。
> 依据：`MCU/hardware/网表.tel` 与实板测量。

## 1. 已确认的焊接问题

| 编号 | 位置 | 现象 | 根因 | 处理 | 日期 |
|---|---|---|---|---|---|
| H-01 | PC5 / POT6（ADC1_IN15） | 六路 ADC 扫描中只有 POT6 读数异常 | 虚焊 | 补焊后读数恢复 | 2026-10-09 |
| H-02 | PE11 / UP2（TIM1_CH2） | 上灯板四路中只有 UP2 无输出，其余三路正常 | 虚焊 | 补焊后信号恢复 | 2026-10-09 |

两处都是**单个引脚/单个网络**的虚焊，现象都是"只有这一路不对"，不影响其它通道。

## 2. 排查惯例

### 2.1 某一路 PWM 无输出

**不要先怀疑软件**。TIM 各通道的配置是对称的（同一个 `sConfigOC`、同一批 `HAL_GPIO_Init`），
如果只有一路不对，几乎一定是硬件。

1. **确认测点。** MCU 引脚号见 `MCU/MCU_接口位置与引脚分配.md` 与下表。注意 UP1/UP2 分别是
   U7 第 **40 / 42** 脚，中间夹着本设计未使用的 **PE10（第 41 脚）**，很容易数错。

2. **用 GPIO 1Hz 自检切开软硬件。** 把
   `MCU/software/test_bringup/Core/Src/main.c` 中的 `BRINGUP_GPIO_PROBE` 置 1，
   并用 `BRINGUP_GPIO_PORT` / `BRINGUP_GPIO_PINS` 指定要比对的引脚
   （默认是 UP1(PE9) 与 UP2(PE11)）：这些脚会改成普通推挽输出、同步输出 1Hz 方波，
   并跳过 PWM 测试。用一个已知正常的脚做 A/B 对比，判断断点位置：

   | 已知正常的脚 | 待查脚（在 MCU 处） | 结论 |
   |---|---|---|
   | 1Hz | 1Hz | MCU 引脚、走线、排阻、连接器都正常，问题在定时器通道 |
   | 1Hz | 无 | 断点在 MCU 引脚本身（QFP 虚焊或引脚损坏） |
   | 连接器侧有 | 连接器侧无（MCU 处有） | 断点在串阻（如 RN1）或连接器焊点 |

   测完把 `BRINGUP_GPIO_PROBE` 置回 0。电机某一路无输出时，把 `BRINGUP_GPIO_PINS`
   改成该路电机的 MCU 引脚即可同样处理（引脚见 3.2 节）。

3. **按链路逐点测量**（见第 3 节），定位到具体焊点后补焊，再重测。

### 2.2 某一路 ADC 读数异常

1. 用单路轮询方式只读该路，确认是否只有这一路异常。
2. 只有一路异常且该路引脚有焊接可疑点时，优先检查 QFP 引脚与相关网络。

## 3. 灯板信号链路（便于逐点测量）

上灯板四路：`U7 → RN1（100Ω 排阻）→ CN7`

| 逻辑 | MCU | U7 脚号 | TIM1 通道 | RN1 组 | 连接器 |
|---|---|---|---|---|---|
| UP1 | PE9 | 40 | CH1 | 1↔8 | CN7.5 |
| UP2 | PE11 | 42 | CH2 | 2↔7 | CN7.4 |
| UP3 | PE14 | 45 | CH4 | 3↔6 | CN7.3 |
| UP4 | PE13 | 44 | CH3 | 4↔5 | CN7.2 |

下灯板三路：`U7 → RN2（100Ω 排阻）→ U29（A2001 四脚连接器）`

| 逻辑 | MCU | U7 脚号 | TIM3 通道 | RN2 组 | 连接器 |
|---|---|---|---|---|---|
| DOWN1 | PB0 | 35 | CH3 | 3↔6 | U29.2 |
| DOWN2 | PB1 | 36 | CH4 | 2↔7 | U29.3 |
| DOWN3 | PB4 | 90 | CH1 | 1↔8 | U29.4 |

上表与 `MCU/hardware/网表.tel` 一致。每个灯板引脚同时挂一组 10kΩ 排阻（RN3/RN4），
属于弱上/下拉，不影响 PWM 波形，测量时不必关心。

### 3.2 电机 PWM 链路

`U7 → 串联 100Ω（R25~R70）→ RZ7899（U8/U9/U13~U18）→ 电机连接器`

| 电机 | MCU | U7 脚号 | 定时器通道 | 串联 100Ω (FI / BI) | RZ7899 | 电机接口 |
|---|---|---|---|---|---|---|
| M1 | PA2 / PA3 | 25 / 26 | TIM2_CH3 / CH4 | R27 / R25 | U8 | CN9 |
| M2 | PA0 / PA1 | 23 / 24 | TIM2_CH1 / CH2 | R33 / R35 | U9 | CN2 |
| M3 | PE5 / PE6 | 4 / 5 | TIM9_CH1 / CH2 | R58 / R56 | U15 | CN3 |
| M4 | PB14 / PB15 | 53 / 54 | TIM12_CH1 / CH2 | R48 / R50 | U13 | CN10 |
| M5 | PC6 / PC7 | 63 / 64 | TIM8_CH1 / CH2 | R52 / R54 | U14 | CN11 |
| M6 | PC9 / PC8 | 66 / 65 | TIM8_CH4 / CH3 | R60 / R62 | U16 | CN1 |
| M7 | PB6 / PB7 | 92 / 93 | TIM4_CH1 / CH2 | R64 / R66 | U17 | CN4 |
| M8 | PB8 / PB9 | 95 / 96 | TIM4_CH3 / CH4 | R68 / R70 | U18 | CN12 |

**电机接口编号与电机编号不对应**（如 M1 在 CN9、M6 在 CN1），插电机前按本表核对。
M6 的 FI/BI 与引脚自然顺序相反，本表已标出。

## 4. 对第二批板与生产的建议

- 首板出现的两处虚焊都在**单个引脚或单组排阻**上，是回流工艺问题，不是设计问题。
- 建议首件检验时对 MCU 四周引脚、以及 RN1~RN4 全部排阻做一次目视或 AOI 复检。
- 排阻单组开路会造成"只有一路无输出"，测量顺序建议固定为：
  `MCU 引脚 → 排阻近端 → 排阻远端 → 连接器引脚`，可以一次定位到具体焊点。

| 状态指示灯 | 四个低有效 LED 点亮/翻转正常 |
| HOME 按键 | 下降沿中断与计数正常 |
| 蜂鸣器 | TIM13_CH1 PWM 输出正常 |
| Linux 电源脉冲 | PB12 脉冲正常（未接 Linux 时观察） |
| 六路 ADC | POT1~POT6 六通道扫描 + DMA 读数正常（POT6 虚焊已修，见 H-01） |
| 上/下灯板 PWM | 七路均输出 20kHz、占空比可控（UP2 虚焊已修，见 H-02） |
| ※ 电机 PWM | 十六路逻辑输入均输出 20kHz、占空比可控 |

※ **电机只验证了 PWM 信号通路，尚未带电机做转动、方向与堵转验证**；首次带电机联调
应按低占空比、单通道、限流供电进行，并先确认 M6 的 FI/BI 反序与各连接器编号。
